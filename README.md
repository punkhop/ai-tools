# ai-tools

Skills, rules and setup for building apps and tools with Claude Code, picked to suit you and installed by Claude itself.

1. Open the setup page, **https://punkhop.github.io/ai-tools/setup/**, tick what you want and copy your answers.
2. Paste them into a new Claude chat (a new T3 Code thread, a session in the Claude desktop app's Code tab, or `claude` in a terminal).

Skipping the page? Paste `Set me up from github.com/punkhop/ai-tools` and Claude asks you the same questions.

To remove it, tell Claude "uninstall ai-tools". Your notes and memory folder stay.
