# ai-tools

Skills, rules and setup for building apps and tools with Claude Code, picked to suit you and installed by Claude itself.

1. Start a new Claude chat: a new T3 Code thread, a session in the Claude desktop app's Code tab, or `claude` in a terminal.
2. Send it `Set me up from github.com/punkhop/ai-tools`.
3. Claude opens the setup page in your browser. Tick what you want, click **Copy my answers**, and paste them back into the chat.

To remove it, tell Claude "uninstall ai-tools". Your notes and memory folder stay.
