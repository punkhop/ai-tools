# T3 Clawd theme

A Claude-inspired theme for T3 Code, light and dark.

Made by [@rohit3a](https://x.com/rohit3a): [github.com/rohit3a/t3-clawd](https://github.com/rohit3a/t3-clawd),
MIT licensed (see `LICENSE`). This copy changes the sidebar:

- No Projects or Add project buttons.
- New chat sits right under search.
- No "Recents" heading.
- Working sits under your recent chats instead of above them.
- Chat rows drop the project badge and the Claude icon.

Claude installs it for you when you tick it on the setup page. By hand: T3 Code → **Settings →
Appearance** → **Add a theme**, then drop in `t3-clawd.json`.

The theme styles T3 Code from the outside, so a T3 Code update can knock a piece of it out of place.
