# Orbit theme

A near-black T3 Code theme built for reading all day, with a chartreuse green accent. Light mode
uses a deep olive green.

- "orbit" at the top of the sidebar.
- New chat is a green plus beside Search.
- No Projects or Add project buttons, and no "Recents" heading.
- Working sits under your recent chats instead of above them.
- Chat rows drop the project badge, the Claude icon and the PR badge.

Orbit is built from [@rohit3a](https://x.com/rohit3a)'s T3 Clawd theme:
[github.com/rohit3a/t3-clawd](https://github.com/rohit3a/t3-clawd), MIT licensed (see `LICENSE`).

Claude installs it for you when you tick it on the setup page. By hand: T3 Code → **Settings →
Appearance** → **Add a theme**, then drop in `orbit.json`.

The theme styles T3 Code from the outside, so a T3 Code update can knock a piece of it out of place.
