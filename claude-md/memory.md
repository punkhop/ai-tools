## Memory

- **Memory:** `~/memory/` (a shortcut to wherever the real folder lives)
  - `sessions/` — session notes from `/note`, plus the HTML pages from `/html`
  - `handoffs/` — briefs written by `/pass` and `/handoff`
  - `transcripts/` — every chat, exported as markdown when a session ends
- **Anything worth keeping goes in `~/memory/`**, never only in `/tmp`.
- `/note` — dated session note in `~/memory/sessions/`. **Run it at the end of every discussion**, as the last step.
