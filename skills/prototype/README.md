# /prototype
Turns "what would this look like?" into a clickable page you can try on your laptop or phone.
Real sample data, buttons that work, empty and error screens — checked before you see it.
Every prototype lives in its own folder under `~/memory/prototypes/`; tell Claude what to change and it edits in place.
Try this: `/prototype a little app to track when I last watered each of my plants`
