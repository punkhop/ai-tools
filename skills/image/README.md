# /image

Make pictures with AI (logos, icons, posters, illustrations) using your own OpenAI or Gemini key.
Every round lands in a gallery page where each image has a number: click to pick, compare two side by side, flip between them.
Each project keeps its references, rounds, picks and finals in one folder, and tells you exactly what every round cost.
Try this: type `/image make me a logo for my bakery` and answer its first questions.
